# 用户故事 — MyVisualMathResolver

本文档列出项目的所有用户故事。每个故事遵循 BDD 的 **作为 / 我希望 / 以便** 格式，验收标准采用 **假设 / 当 / 那么** 形式。

---

## US-001：远程听写时自动跳转至下一个词

**作为** 一位远程给孩子听写的家长，
**我希望** 智能体能自动检测孩子已接近写完当前词语，并通知我报出下一个词，
**以便** 孩子不需要每次手动发出"准备好了"的信号，让听写过程更顺畅、更高效，就像家长在旁边亲自监督一样。

---

### 验收标准

#### 场景 1：智能体检测到接近完成，通知家长跳转
- **假设** 家长已开启远程听写会话，并已向孩子朗读了一个词语
- **当** 智能体观察到孩子已写出该词全部（或接近全部）的笔画／字符时
- **那么** 智能体通知家长孩子已准备好听下一个词，无需等待孩子发出任何“准备好”信号

#### 场景 2：孩子尚未写完——智能体等待
- **假设** 已报出一个词，孩子仍在书写中
- **当** 书写区域中只检测到该词的部分内容时
- **那么** 智能体不跳转，继续监测，直到检测到接近完成

#### 场景 3：孩子短暂停笔——智能体在宽限期后自动跳转
- **假设** 智能体已检测到当前词接近完成
- **当** 孩子的笔停止移动达到可配置的宽限时间（例如 2 秒）时
- **那么** 智能体将此次停顿视为写完，并通知家长报出下一个词

#### 场景 4：接近完成后孩子又继续修改
- **假设** 智能体已初步判定接近完成
- **当** 孩子在宽限期内继续书写（例如修改某个笔画）时
- **那么** 智能体重置接近完成的倒计时，重新等待

#### 场景 5：最后一个词写完
- **假设** 智能体检测到最后一个词接近完成
- **当** 宽限期结束时
- **那么** 智能体播报听写会话结束，而不是继续跳转至下一个词

#### 场景 6：家长在听写过程中暂停会话
- **假设** 听写会话正在进行，自动跳转功能已开启
- **当** 家长显式暂停会话时
- **那么** 即使检测到接近完成，智能体也停止自动跳转，等待家长恢复会话

#### 场景 7：智能体通知家长下一个词即将开始
- **假设** 智能体已检测到孩子完成了当前词语的书写
- **当** 宽限期结束时
- **那么** 智能体向家长发送实时通知（例如推送提醒或应用内提示），提示现在应报出下一个词，由家长在合适时机亲自朗读

---

### 备注
- "接近完成"阈值（例如 ≥ 80% 的预期笔画／字符）应可配置。
- 自动跳转前的宽限时间应可配置（默认值：2 秒）。
- 自动跳转行为应可切换；部分家长可能更倾向于手动跳转。
- 检测机制可依赖实时摄像头画面、触控笔事件流或 OCR，具体实现细节不在本故事范围内。
- 待确认问题：对于含有可选字符或存在地区拼写差异的词语，智能体应如何处理？
